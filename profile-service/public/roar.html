HOW THE ROAR WORKS

The simulated rewards pool releases evenly by UTC time, stopping exactly at the event deadline. Live token and USD amounts are estimates using the current rank, not vested earnings. The verified final snapshot alone fixes the final Top 100 allocations. A delayed final snapshot keeps allocations pending; post-event blocks cannot determine them. Claims will be available only after closing and verification in a future rewards page. This private test has no deposits, claim transactions or real payouts.

Private ULTON test. Contract and burn addresses are excluded; project-wallet exclusions for $LOAD will be configured before launch. Points equal the current token balance multiplied by (1 + boost / 100). The original 100-position draw weighting is confirmed.

The page checks for a new published snapshot every five minutes. Snapshot age updates continuously. At the deadline the timer stops, while final results remain pending verification. Values remain fixed at the verified block shown above; this does not mean a new on-chain scan completes every five minutes. This test does not activate prizes.

The full 100-wallet model targets 60% of draw weighting for positions 1–25, 30% for 26–50 and 10% for 51–100. Displayed chances are the confirmed full 100-wallet model, not active prize eligibility. If fewer than 100 wallets qualify, draw weighting must be finalized before the draw.

From 21 October 2026, events run on days 1–10, 11–20 and 21–month end, starting at 00:00:00 UTC and ending at 23:59:59 UTC. The last event includes day 31; February ends on day 28 or 29. Maximum boost is +250% (3.5× points), earned in +0.01 percentage-point steps over eight days. Short February events can end before a newly started boost reaches the maximum. The current transition test ends on 20 October 2026; earlier snapshots retain their original boost rules. Existing holders start accruing boost at the event opening. A new wallet starts on a verified DEX purchase; additional purchases preserve the wallet’s boost. Any sale or outgoing transfer resets the boost; a new purchase restarts it. All boost resets at the next event opening. New purchases count until the final second.
